# docs/research — AI-generated strategy theories

This folder holds strategy **theories generated by the Quant Researcher skill** (Skills page in
the app → backend `services/quant_researcher.py`). Each file is one self-contained markdown
strategy spec named `{CODE}-{HORIZON}-{Name}-{SYM}-{NNN}.md` (e.g. `MR-MD-VolFade-ES-001.md`).

These are **machine-authored ideas, not validated strategies** — treat them as research leads.
They have not been backtested, t-tested, or fee-checked. Promote one to a real strategy only after
implementing and walk-forward testing it.

> Kept deliberately separate from [`../txt-strategies/`](../txt-strategies/), which holds the
> human-authored EasyLanguage reference corpus (`[CODE-TF-NAME-SYM-NNN].txt`).
